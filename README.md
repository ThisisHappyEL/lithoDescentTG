# ⛏️ LithoDescent (Telegram Mini App)

Вертикальный пошаговый симулятор шахтерских экспедиций в умирающем подземном мире. 
Вдохновлен механиками **Battle Brothers** (генерация, предыстории, экипировка) и атмосферой **Darkest Dungeon**.

Разрабатывается специально под мобильный формат и экосистему **Telegram Mini Apps (TMA)**.

---

## 🛠️ Стек технологий
* **Core:** React 18/19, TypeScript
* **State Management:** Zustand
* **Styling:** Tailwind CSS v4
* **Icons:** Lucide React
* **Build Tool:** Vite

---

## 🎮 Текущий функционал (MVP)
* **Мобильный вьюпорт:** Полная фиксация интерфейса под экраны смартфонов и Telegram-клиент.
* **Главный экран (Базо-Шахта):** 
  * Верхняя панель станции с циклом и ресурсами (свечи).
  * Центральная база с быстрым доступом к службам станции.
  * Скроллируемая сетка глубин шахты с механикой неразведанных секторов ("Мрак").
  * Выдвижное досье текущего биома с угрозами и ресурсами.
* **Система персонажей (Battle Brothers-like):**
  * Процедурная генерация погруженцев на основе сословий и профессий (Тиры 0–5).
  * Генерация славянско-средневековых имен и прозвищ.
  * Система найма и содержания (зарплата за цикл).
* **Склад и Экипировка:**
  * Индивидуальный лист персонажа с распределением очков характеристик.
  * Формула экспоненциального набора опыта за проведенные рабочие часы.
  * Динамическая экипировка оружия и одежд со склада базы.
  * Просмотр боевых приемов и навыков, открываемых экипированным оружием.

## 🚀 Запуск проекта локально

### 1. Клонировать репозиторий:
```bash
git clone https://github.com/<ТВОЙ_НИК>/<ИМЯ_РЕПО>.git
cd lithoDescentTG
```

### 2. Установить зависимости:
```bash
npm install
```

### 3. Запустить dev-сервер:
```bash
npm run dev
```
